# ObsTracker 采集层设计 v1

> 状态：设计稿（draft）。本文聚焦「数据如何被采集并落盘」，不含报表/归类/弱推断的具体实现。

---

## 1. 职责边界（核心原则）

采集层**只落盘原始事实**，不做任何判断：

- ❌ 不判断「阅读 vs 写作」
- ❌ 不计算 folder 递归归类
- ❌ 不判定「心流时段」
- ✅ 只记录：谁、何时、对哪篇笔记、停留多久、编辑了多少、何时结束

所有「判断」由**报表层事后从原始事件重算**。好处：规则升级只改报表层，历史数据一字节不动。

---

## 2. 落盘事件模型（方案 B：只落 2 类）

> 对基线文档 6.1「7 类事件」的收敛说明：
> `note_open` / `note_switch` / `note_close` 合并为 `session` 的起止与 `endedBy`；
> `heartbeat` 不落盘（仅内存累积）；`idle` / `app_blur` 以 `endedBy` 体现；`edit` 保留。

### 2.1 `session` —— 一段连续活跃停留

一次「打开某笔记并停留」的完整段落。

```json
{
  "type": "session",
  "ts": 1754985600000,
  "endTs": 1754986834000,
  "notePath": "哲学/西方/康德.md",
  "noteTitle": "康德",
  "mode": "source",
  "activeSeconds": 1234,
  "endedBy": "switch",
  "totalChars": 8421,
  "totalWords": 1203
}
```

- `mode`：`source`（源码）/ `preview`（预览，含 live preview 与 reading view）—— 对齐 Obsidian `MarkdownView.getMode()` 的真实返回值。
- `activeSeconds`：实际活跃秒数，已排除 idle 尾段。**活跃区间 = `[ts, ts + activeSeconds×1000]`**，所有时长分摊以此区间为准；`endTs` 仅为落盘时刻（用于排序/审计），**不参与时长计算**。
- `endedBy`：`switch`（切到别的笔记）/ `close`（关闭）/ `idle`（空闲超时）/ `blur`（窗口失焦）/ `shutdown`（应用退出）。
- `totalChars` / `totalWords`：session 开始时的文档总字数快照（采集层读文件统计一次），支撑「总字数快照」「单篇字数增长曲线」；仅存统计数字，不存正文。

### 2.2 `edit` —— 编辑增量

每次编辑操作落一条，用于写作/阅读弱推断与字数统计。

```json
{
  "type": "edit",
  "ts": 1754985600000,
  "notePath": "哲学/西方/康德.md",
  "charDelta": 12,
  "wordDelta": 3
}
```

- `charDelta`：本次净增字符数（中文一字 = 1）。
- `wordDelta`：本次净增词数（英文按空格分词）。
- 双口径同时记录，报表层可切换中文/英文口径。

## 3. 采集来源（Obsidian API → 事件映射）

| 触发源 | 动作 |
|---|---|
| `active-leaf-change` | 结束旧 session（`endedBy=switch`），开启新 session |
| CodeMirror 编辑器 change | 累计并落盘 `edit` 事件 |
| `window` blur / focus | blur 结束 session（`endedBy=blur`），focus 恢复 |
| 定时心跳（30s，仅内存） | 累积 `activeSeconds`、检测空闲 |
| 笔记关闭 / 应用退出 | 结束 session（`endedBy=close` / `shutdown`） |

---

## 4. 阈值（默认值，均做设置项）

- 心跳间隔：30 秒（仅内存，不落盘）
- 空闲判定：无交互 3 分钟 → 结束 session（`endedBy=idle`）
- 失焦：立即结束 session（`endedBy=blur`）
- 极短 session（< 2 秒）丢弃，减噪（阈值可配）

排除路径：`.obstracker/`、`.obsidian/` 及用户自定义路径（可配）下的文件，采集层一律不记录。

---

## 5. 写盘策略

- append-only，按天分文件：`.obstracker/events-YYYY-MM-DD.jsonl`
- 位置默认 `.obstracker/`，可配置
- 插件自身配置走 Obsidian `data.json`，与原始事件分离

---

## 6. 明确不落盘的内容

- heartbeat 原始心跳（内存累积进 `activeSeconds`）
- 弱推断结论（报表层算）
- folder 归类结果（报表层算）
- 笔记正文 / 选中文本 / 实际输入字符串

---

## 7. 待定（实现时再定，不影响 schema）

- session 跨天是否拆成两条（倾向：拆，便于按天归档）
- edit 事件的写盘批量策略（逐条 vs 微缓冲）

---

## 8. 已知限制（MVP 接受，后续可扩展）

- **分屏（split pane）**：只跟踪当前活跃 leaf，非活跃 pane 的停留不计入；分屏场景会低估总时长。
- **IME 中文输入**：拼音组合期间可能产生中间态 change，`charDelta` 可能短暂虚高/虚低；MVP 接受，后续可用 composition 事件校正。
- **`noteTitle` / `notePath` 为打开时刻快照**：重命名后历史记录保留旧值，不做迁移。
