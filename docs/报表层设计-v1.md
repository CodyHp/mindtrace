# MindTrace 报表层设计 v1

> 状态：设计稿（draft）。本文定义「如何从原始事件算出报表」，是插件差异化的核心。

---

## 1. 计算管线

```
原始事件(session/edit)
  → 会话重建（还原每篇笔记的活跃区间）
  → folder 递归归类
  → 读写弱推断（每个 session 拆出 read/write 秒数）
  → 聚合（日/周/月 × folder × 时段 × 类型）
  → 图表输出
```

纯离线、纯规则，数据不出库。

---

## 2. folder 递归归类

- 从 `notePath` 提取目录层级（含最细粒度的文件级，去扩展名）：`哲学/西方/康德.md` → 同时计入「哲学」「哲学/西方」「哲学/西方/康德」三级。
- folder 以**累积路径**作为唯一标识（避免同名子目录冲突），每级均可独立出榜、下钻。
- 每个 session 的 `activeSeconds` 与字数**同时上卷**到每一级。
- 父目录 = 其下所有子目录与文件之和，各级独立可查、可下钻。
- 根目录（无目录）笔记归入独立「未分类」桶，默认计入报表。
- 排除路径：`.mindtrace/`、`.obsidian/`、用户自定义路径（可配），不计入。
- 历史数据保留当时的 `notePath` 快照，不做重命名迁移。

### 2.1 时长分摊到小时桶

- 每个 session 的活跃区间 `[ts, ts + activeSeconds×1000]` 按**小时边界**切分，各段时长落入对应小时桶。
- 跨小时 / 跨天的 session 因此被正确拆分，不重复、不丢失。
- 切分基于活跃区间，而非 `endTs`（`endTs` 含 idle 尾段，不参与时长）。

---

## 3. 读写弱推断（在报表层执行）

- 规则：**5 分钟固定分片**（对齐 session 起点），片内累计 `charDelta` ≥ 20 字 → 判「写作」，否则「阅读」；叠加 `mode` 修正（`preview` 偏向阅读）。
- 算法：
  1. 取 session 活跃区间 `[ts, ts + activeSeconds×1000]`，按 5 分钟切分（首/尾片可能不足 5 分钟）。
  2. 每片累加 `edit` 事件（`ts` 落在片内、`notePath` 匹配）的 `charDelta`。
  3. 片内累计 `charDelta` ≥ 20 → 写作片，否则阅读片。
  4. 汇总写作片秒数 = `writeSeconds`，其余 = `readSeconds`；`mode=preview` 且片内无编辑时归阅读。
- 新增字数（`charDelta` / `wordDelta` 净增）计入该 session 所属笔记及其所有上级 folder。
- 总字数快照取 session 的 `totalChars` / `totalWords` 字段（采集层采样），支撑「总字数快照」「单篇字数增长曲线」。

## 4. 聚合维度与指标

| 维度 | 取值 |
|---|---|
| 时间 | 日 / 周 / 月，24 小时小时粒度 |
| 分类 | folder 各级（默认顶级 1 级，深度可配） |
| 类型 | 阅读 / 写作 / 总计 |
| 指标 | 时长（activeSeconds）、新增字数、编辑次数、打开次数（session 数）、文档总字数快照 |

## 5. 报表维度全景

维度分四组呈现，全部由 `session + edit` 事后重算，采集层零改动。

### A. 时间画像（何时在用）

| 维度 | 说明 |
|---|---|
| 时段 × 主题矩阵 | 24h × folder 热力图，差异化灵魂 |
| 星期分布 | 周几最活跃 |
| 每日节奏 | 每天时长、首次/末次打开时间、连续天数 streak |
| 创作高峰时段 | 按小时汇总 writeSeconds |

### B. 主题画像（内容维度）

| 维度 | 说明 |
|---|---|
| folder 时长排行 | 条形图，可下钻到子目录/单文件 |
| 主题间注意力流向 | 从「哲学」切到「计算机」的频率（桑基/和弦图），知识流转画像 |
| 主题读写偏好 | 哲学多读少写、计算机多写 |

### C. 文档画像（单篇维度）

| 维度 | 说明 |
|---|---|
| 高频文档排行 | 按 session 次数排序 |
| 遗忘提醒 | 按最后访问时间排序，识别「很久没看」 |
| 复访模式 | 打开次数 × 单次时长 → 复习型 / 深耕型 / 写不动型 |
| 单篇字数增长曲线 | 一篇笔记的产出轨迹 |

### D. 跨维度

| 维度 | 说明 |
|---|---|
| 心流时段 | 后置 |
| 读写时段对比 | 哪个时段爱读、哪个时段爱写 |

### MVP / 二期划分

- **MVP**（单条聚合即可出，成本低）：
  1. 时段 × 主题矩阵
  2. folder 时长排行
  3. 阅读 vs 写作占比
  4. 字数趋势（新增 + 总字数快照）
  5. 高频文档排行
  6. 遗忘提醒
  7. 明细时间线
- **二期**（成本中，图形更重）：
  - 主题间注意力流向（桑基/和弦图）
  - 复访模式、单篇字数增长曲线
  - 每日节奏 streak、创作高峰时段、读写时段对比
- **注意事项**：「遗忘提醒」需区分「没看」与「文件被删/移走」——用 session 的 notePath 快照 + 当前 vault 文件清单比对，无需额外采集。

## 6. 输出形态

- 独立 dashboard 笔记 + ```` ```mindtrace ```` 代码块。
- 打开时实时渲染 + 提供「刷新报表」命令手动触发；不做定时重写文件。
- 图表库离线打包进插件（chart.js / echarts，实现期选型），不联网。
